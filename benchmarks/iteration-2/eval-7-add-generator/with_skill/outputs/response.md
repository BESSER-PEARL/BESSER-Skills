# Adding a GraphQL Generator to BESSER: Step-by-Step Guide

This guide walks you through the complete process of adding a new GraphQL code generator to BESSER, from creating the package to writing tests and documentation.

---

## Step 1: Create the Generator Package

Create the following directory structure:

```
besser/generators/graphql/
    __init__.py
    graphql_generator.py
    templates/
        schema.graphql.j2
```

**`besser/generators/graphql/__init__.py`**:

```python
from .graphql_generator import GraphQLGenerator
```

This export allows users to import the generator with:

```python
from besser.generators.graphql import GraphQLGenerator
```

---

## Step 2: Implement GeneratorInterface

Every BESSER generator must implement the `GeneratorInterface` abstract base class, which requires a constructor accepting a `model` and `output_dir`, and a `generate()` method.

**`besser/generators/graphql/graphql_generator.py`**:

```python
import os
from jinja2 import Environment, FileSystemLoader
from besser.generators import GeneratorInterface
from besser.BUML.metamodel.structural import DomainModel


class GraphQLGenerator(GeneratorInterface):
    """Generates a GraphQL schema from a B-UML domain model.

    The generator produces a `.graphql` file containing type definitions,
    queries, and mutations derived from the classes, attributes, and
    associations in the domain model.

    Args:
        model: A B-UML DomainModel instance.
        output_dir: Directory where the generated file will be written.
            Defaults to the current working directory if not provided.
    """

    # Mapping from B-UML primitive types to GraphQL scalar types
    TYPE_MAP = {
        "str": "String",
        "string": "String",
        "int": "Int",
        "integer": "Int",
        "float": "Float",
        "bool": "Boolean",
        "boolean": "Boolean",
        "date": "String",
        "datetime": "String",
        "time": "String",
    }

    def __init__(self, model: DomainModel, output_dir: str = None):
        super().__init__(model, output_dir)

    def generate(self):
        """Generate a GraphQL schema file from the B-UML model."""
        templates_path = os.path.join(os.path.dirname(__file__), "templates")
        env = Environment(
            loader=FileSystemLoader(templates_path),
            trim_blocks=True,
            lstrip_blocks=True,
        )
        # Register the type-mapping helper as a Jinja2 filter
        env.filters["graphql_type"] = self._map_type

        template = env.get_template("schema.graphql.j2")

        classes = sorted(self.model.get_classes(), key=lambda c: c.name)
        associations = sorted(self.model.associations, key=lambda a: a.name)

        output = template.render(
            classes=classes,
            associations=associations,
        )

        file_path = self.build_generation_path("schema.graphql")
        with open(file_path, "w", encoding="utf-8") as f:
            f.write(output)

    @staticmethod
    def _map_type(buml_type_name: str) -> str:
        """Map a B-UML type name to the corresponding GraphQL scalar type."""
        return GraphQLGenerator.TYPE_MAP.get(buml_type_name.lower(), buml_type_name)
```

Key points:

- Call `super().__init__(model, output_dir)` -- this sets up `self.model` and `self.output_dir`.
- Use `self.build_generation_path(filename)` to resolve the correct output file path.
- Sort classes and associations by name to ensure **deterministic output** (same model always produces the same file).
- Use `os.path.join(os.path.dirname(__file__), "templates")` to locate templates relative to the generator module.

## Step 3: Write the Jinja2 Template

**`besser/generators/graphql/templates/schema.graphql.j2`**:

```jinja2
# Generated by BESSER GraphQLGenerator
# Do not edit manually.

{% for cls in classes %}
type {{ cls.name }} {
  {% for attr in cls.attributes|sort(attribute='name') %}
  {{ attr.name }}: {{ attr.type.name|graphql_type }}{% if not attr.is_optional %}!{% endif %}

  {% endfor %}
  {# Add relationship fields from associations #}
  {% for assoc in associations %}
  {% for end in assoc.ends %}
  {% if end.type != cls %}
  {% set other_end = end %}
  {% for my_end in assoc.ends %}
  {% if my_end.type == cls %}
  {{ other_end.name }}: {% if other_end.multiplicity.max > 1 %}[{{ other_end.type.name }}!]{% else %}{{ other_end.type.name }}{% endif %}

  {% endif %}
  {% endfor %}
  {% endif %}
  {% endfor %}
  {% endfor %}
}

{% endfor %}
type Query {
  {% for cls in classes %}
  all{{ cls.name }}s: [{{ cls.name }}!]!
  {{ cls.name[0]|lower }}{{ cls.name[1:] }}ById(id: ID!): {{ cls.name }}
  {% endfor %}
}

type Mutation {
  {% for cls in classes %}
  create{{ cls.name }}(input: {{ cls.name }}Input!): {{ cls.name }}!
  update{{ cls.name }}(id: ID!, input: {{ cls.name }}Input!): {{ cls.name }}!
  delete{{ cls.name }}(id: ID!): Boolean!
  {% endfor %}
}

{% for cls in classes %}
input {{ cls.name }}Input {
  {% for attr in cls.attributes|sort(attribute='name') %}
  {{ attr.name }}: {{ attr.type.name|graphql_type }}
  {% endfor %}
}

{% endfor %}
```

This template generates:

- A `type` definition for each class in the domain model, including attributes and relationship fields.
- A `Query` type with `all<Type>s` (list) and `<type>ById` (single lookup) for each class.
- A `Mutation` type with `create`, `update`, and `delete` operations for each class.
- An `input` type for each class, used as the argument to create/update mutations.

## Step 4: Register in the Web Editor Backend

Edit the file `besser/utilities/web_modeling_editor/backend/config/generators.py` and add the GraphQL generator to the `GENERATORS` dictionary.

First, add the import at the top of the file:

```python
from besser.generators.graphql import GraphQLGenerator
```

Then add the entry inside the `GENERATORS` dictionary:

```python
GENERATORS = {
    # ... existing generators ...
    "graphql": GeneratorInfo(
        generator_class=GraphQLGenerator,
        output_type="file",
        file_extension=".graphql",
        category="api",
        requires_class_diagram=True,
    ),
}
```

Also update the `get_filename_for_generator()` function in the same file if it uses explicit filename mappings, adding:

```python
"graphql": "schema.graphql",
```

The `GeneratorInfo` fields:

| Field | Value | Reason |
|-------|-------|--------|
| `generator_class` | `GraphQLGenerator` | The class to instantiate |
| `output_type` | `"file"` | Single file output (use `"zip"` for multi-file generators) |
| `file_extension` | `".graphql"` | The file type produced |
| `category` | `"api"` | Logical grouping in the editor UI |
| `requires_class_diagram` | `True` | The generator needs a DomainModel as input |

## Step 5: Write Tests

Create the test file at `tests/generators/graphql/test_graphql_generator.py`:

```python
import os
import pytest
from besser.BUML.metamodel.structural import (
    DomainModel,
    Class,
    Property,
    BinaryAssociation,
    Multiplicity,
    StringType,
    IntegerType,
    FloatType,
    BooleanType,
)
from besser.generators.graphql import GraphQLGenerator


# ---------------------------------------------------------------------------
# Fixtures
# ---------------------------------------------------------------------------

@pytest.fixture
def simple_model():
    """A single-class model for basic tests."""
    name_attr = Property(name="name", type=StringType)
    age_attr = Property(name="age", type=IntegerType)
    person = Class(name="Person", attributes={name_attr, age_attr})
    return DomainModel(name="SimpleModel", types={person})


@pytest.fixture
def associated_model():
    """A two-class model with an association for relationship tests."""
    title_attr = Property(name="title", type=StringType)
    pages_attr = Property(name="pages", type=IntegerType)
    book = Class(name="Book", attributes={title_attr, pages_attr})

    name_attr = Property(name="name", type=StringType)
    author = Class(name="Author", attributes={name_attr})

    writes = BinaryAssociation(
        name="writes",
        ends={
            Property(name="books", type=book, multiplicity=Multiplicity(0, "*")),
            Property(name="author", type=author, multiplicity=Multiplicity(1, 1)),
        },
    )

    return DomainModel(
        name="LibraryModel",
        types={book, author},
        associations={writes},
    )


@pytest.fixture
def output_dir(tmp_path):
    """Use pytest's tmp_path for auto-cleaned output."""
    return str(tmp_path)


# ---------------------------------------------------------------------------
# Tests: File Generation
# ---------------------------------------------------------------------------

class TestFileGeneration:
    """Verify that the generator creates the expected output file."""

    def test_output_file_is_created(self, simple_model, output_dir):
        gen = GraphQLGenerator(model=simple_model, output_dir=output_dir)
        gen.generate()
        assert os.path.exists(os.path.join(output_dir, "schema.graphql"))

    def test_output_file_is_not_empty(self, simple_model, output_dir):
        gen = GraphQLGenerator(model=simple_model, output_dir=output_dir)
        gen.generate()
        file_path = os.path.join(output_dir, "schema.graphql")
        assert os.path.getsize(file_path) > 0


# ---------------------------------------------------------------------------
# Tests: Type Definitions
# ---------------------------------------------------------------------------

class TestTypeDefinitions:
    """Verify that GraphQL type definitions are generated correctly."""

    def test_class_becomes_graphql_type(self, simple_model, output_dir):
        gen = GraphQLGenerator(model=simple_model, output_dir=output_dir)
        gen.generate()
        content = self._read_output(output_dir)
        assert "type Person {" in content

    def test_string_attribute_mapped(self, simple_model, output_dir):
        gen = GraphQLGenerator(model=simple_model, output_dir=output_dir)
        gen.generate()
        content = self._read_output(output_dir)
        assert "name: String" in content

    def test_integer_attribute_mapped(self, simple_model, output_dir):
        gen = GraphQLGenerator(model=simple_model, output_dir=output_dir)
        gen.generate()
        content = self._read_output(output_dir)
        assert "age: Int" in content

    @staticmethod
    def _read_output(output_dir):
        with open(os.path.join(output_dir, "schema.graphql"), encoding="utf-8") as f:
            return f.read()


# ---------------------------------------------------------------------------
# Tests: Queries and Mutations
# ---------------------------------------------------------------------------

class TestQueriesAndMutations:
    """Verify that Query and Mutation types are generated."""

    def test_query_type_generated(self, simple_model, output_dir):
        gen = GraphQLGenerator(model=simple_model, output_dir=output_dir)
        gen.generate()
        content = self._read_output(output_dir)
        assert "type Query {" in content
        assert "allPersons:" in content
        assert "personById(id: ID!): Person" in content

    def test_mutation_type_generated(self, simple_model, output_dir):
        gen = GraphQLGenerator(model=simple_model, output_dir=output_dir)
        gen.generate()
        content = self._read_output(output_dir)
        assert "type Mutation {" in content
        assert "createPerson(" in content
        assert "updatePerson(" in content
        assert "deletePerson(id: ID!): Boolean!" in content

    def test_input_type_generated(self, simple_model, output_dir):
        gen = GraphQLGenerator(model=simple_model, output_dir=output_dir)
        gen.generate()
        content = self._read_output(output_dir)
        assert "input PersonInput {" in content

    @staticmethod
    def _read_output(output_dir):
        with open(os.path.join(output_dir, "schema.graphql"), encoding="utf-8") as f:
            return f.read()


# ---------------------------------------------------------------------------
# Tests: Associations
# ---------------------------------------------------------------------------

class TestAssociations:
    """Verify that associations produce relationship fields."""

    def test_association_fields_present(self, associated_model, output_dir):
        gen = GraphQLGenerator(model=associated_model, output_dir=output_dir)
        gen.generate()
        content = self._read_output(output_dir)
        # Author should have a 'books' field (list), Book should have 'author' field
        assert "type Author {" in content
        assert "type Book {" in content

    def test_multiple_classes_generate_queries(self, associated_model, output_dir):
        gen = GraphQLGenerator(model=associated_model, output_dir=output_dir)
        gen.generate()
        content = self._read_output(output_dir)
        assert "allBooks:" in content
        assert "allAuthors:" in content
        assert "createBook(" in content
        assert "createAuthor(" in content

    @staticmethod
    def _read_output(output_dir):
        with open(os.path.join(output_dir, "schema.graphql"), encoding="utf-8") as f:
            return f.read()


# ---------------------------------------------------------------------------
# Tests: Determinism
# ---------------------------------------------------------------------------

class TestDeterminism:
    """Verify that the generator produces identical output on repeated runs."""

    def test_output_is_deterministic(self, associated_model, tmp_path):
        dir1 = str(tmp_path / "run1")
        dir2 = str(tmp_path / "run2")
        os.makedirs(dir1)
        os.makedirs(dir2)

        gen1 = GraphQLGenerator(model=associated_model, output_dir=dir1)
        gen1.generate()

        gen2 = GraphQLGenerator(model=associated_model, output_dir=dir2)
        gen2.generate()

        with open(os.path.join(dir1, "schema.graphql"), encoding="utf-8") as f:
            output1 = f.read()
        with open(os.path.join(dir2, "schema.graphql"), encoding="utf-8") as f:
            output2 = f.read()

        assert output1 == output2


# ---------------------------------------------------------------------------
# Tests: Type Mapping
# ---------------------------------------------------------------------------

class TestTypeMapping:
    """Verify the B-UML to GraphQL type mapping helper."""

    @pytest.mark.parametrize(
        "buml_type,expected_graphql",
        [
            ("str", "String"),
            ("string", "String"),
            ("int", "Int"),
            ("integer", "Int"),
            ("float", "Float"),
            ("bool", "Boolean"),
            ("boolean", "Boolean"),
        ],
    )
    def test_primitive_type_mapping(self, buml_type, expected_graphql):
        result = GraphQLGenerator._map_type(buml_type)
        assert result == expected_graphql

    def test_unknown_type_passed_through(self):
        result = GraphQLGenerator._map_type("CustomType")
        assert result == "CustomType"
```

### Running the Tests

```bash
# Run only the GraphQL generator tests
python -m pytest tests/generators/graphql/ -v

# Run with keyword filter
python -m pytest -k "graphql" -v

# Run all tests to make sure nothing is broken
python -m pytest
```

### What These Tests Cover

| Category | What is tested |
|----------|---------------|
| **File generation** | Output file exists and is non-empty |
| **Type definitions** | Classes become GraphQL `type` blocks; attributes are correctly typed |
| **Queries/Mutations** | `Query`, `Mutation`, and `input` types are generated for each class |
| **Associations** | Related classes produce relationship fields |
| **Determinism** | Two runs on the same model produce identical output |
| **Type mapping** | B-UML primitive types map to correct GraphQL scalars |

## Step 6: Document the Generator

Create the documentation file at `docs/source/generators/graphql.rst`:

```rst
GraphQL Generator
=================

The **GraphQL Generator** produces a GraphQL schema file (``.graphql``) from a
B-UML domain model. The schema includes type definitions, queries, mutations,
and input types.

Prerequisites
-------------

- BESSER installed (``pip install besser``)
- A B-UML domain model

Usage
-----

.. code-block:: python

   from besser.BUML.metamodel.structural import (
       DomainModel, Class, Property, StringType, IntegerType,
   )
   from besser.generators.graphql import GraphQLGenerator

   # Define a simple model
   name = Property(name="name", type=StringType)
   age = Property(name="age", type=IntegerType)
   person = Class(name="Person", attributes={name, age})
   model = DomainModel(name="MyApp", types={person})

   # Generate
   gen = GraphQLGenerator(model=model, output_dir="./output")
   gen.generate()

Output
------

The generator produces a single ``schema.graphql`` file containing:

- **Type definitions** for each class in the domain model
- **Query type** with list and by-ID queries for each type
- **Mutation type** with create, update, and delete operations
- **Input types** for create/update mutation arguments

Example output:

.. code-block:: graphql

   type Person {
     name: String
     age: Int
   }

   type Query {
     allPersons: [Person!]!
     personById(id: ID!): Person
   }

   type Mutation {
     createPerson(input: PersonInput!): Person!
     updatePerson(id: ID!, input: PersonInput!): Person!
     deletePerson(id: ID!): Boolean!
   }

   input PersonInput {
     name: String
     age: Int
   }

Type Mapping
------------

The generator maps B-UML primitive types to GraphQL scalar types:

.. list-table::
   :header-rows: 1

   * - B-UML Type
     - GraphQL Type
   * - ``StringType``
     - ``String``
   * - ``IntegerType``
     - ``Int``
   * - ``FloatType``
     - ``Float``
   * - ``BooleanType``
     - ``Boolean``
   * - Custom types
     - Passed through as-is
```

Then add `graphql` to the table of contents in `docs/source/generators.rst`:

```rst
.. toctree::

   generators/graphql
```
